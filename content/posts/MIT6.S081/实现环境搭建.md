## 通过一个docker镜像来实现
PS：可通过arch命令查看当前处理器的架构，根据架构选择相关的镜像文件，否则会存在由于架构不兼容导致不能正确启动容器的问题。
### x86_64
链接: https://pan.baidu.com/s/1v8y2SR0L4vnQRPT8ojQkKw 
提取码: d0db
### arm64
链接: https://pan.baidu.com/s/1IEqDUztYLUIu7dyOycBwCg?pwd=a4ub 
提取码: a4ub 

1. 拉取实验仓库到本地
xv6的实验代码
```bash
git clone git://g.csail.mit.edu/xv6-labs-2021

cd xv6-labs-2021

git checkout util
```

2. 在当前文件夹下有一个ubuntu.tar文件，根据该文件创建一个镜像
```bash
docker import ubuntu.tar ubuntu
```
3. 根据该镜像启动一个容器,并直接挂载到本地的文件路径 本地更改也会影响到镜像里，
```bash
docker run -it -v ${/Users/cheng-xuanzhu/MIT6 S081}:/root --name ubuntu ubuntu bash
```
